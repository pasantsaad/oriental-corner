# Oriental Corner

Hand-woven Egyptian wool & cotton kilims, sold direct from the workshop in Cairo.

## Pages

- `/` — Home
- `/shop` — Special Collection, with Size / Style / Sort filters
- `/shop/{code}` — Individual kilim page, with care guide and WhatsApp enquiry
- `/craft` — Our Craft: the heritage behind the weaving
- `/showroom` — Visit the showroom: address, hours, map and contact form

## Ordering

Customers add kilims to the basket and check out with Cash on Delivery — no account,
no login. A confirmed order opens WhatsApp with the full receipt pre-filled, and is
posted to the Google Sheet once that link is connected.

## Development

You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
